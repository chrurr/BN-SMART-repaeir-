# BN SMART Repair V3

نسخة تطوير مركزة على دورة إصلاح الهاتف في BN SMART.

## الوظائف الأساسية
- زبون + رقم هاتف
- هاتف: الشركة، الموديل، اللون، حالة الجهاز، العطل، تاريخ الدخول وموعد الجاهزية
- وصل تلقائي + QR لتتبع الحالة
- حالات الإصلاح: قيد الاصلاح / تم اصلاحه / لايصلح
- فتح WhatsApp برسالة جاهزية عند تغيير الحالة إلى تم اصلاحه
- بطاقة جهاز قابلة للطباعة مع اسم الزبون، الهاتف، نوع الجهاز، العطل، الموعد ورقم الوصل + QR
- قطع غيار لكل إصلاح مع تكلفة الشراء وسعرها على الزبون والكمية
- حساب المدفوع والمتبقي وتكلفة القطع والربح بعد الاستلام
- Manager + Collaborator بحسابات منفصلة وصلاحيات Backend
- سجل نشاطات
- Multi-Tenant عبر shop_id وPostgreSQL RLS
- PWA وواجهة عربية RTL

## تشغيل محلي
1. `npm install`
2. أنشئ `.env` انطلاقًا من `.env.example`
3. ضع `DATABASE_URL` و`JWT_SECRET`
4. `npm start`
